## 지원 범위와 설치 참고

네이버 공식 도보 경로 화면을 연결하며, 실제 안내 시작은 네이버 앱에서 필요할 수 있습니다. 완전히 숨긴 백그라운드 자동 안내 시작이나 실제 보행 경로·네이버 음성 안내는 검증하지 않았습니다. 새 ChatGPT 사진 질문은 Aria 화면이 보일 때 처리되며 로그인과 실행 중인 카메라가 필요합니다. 실제 ChatGPT 서버 응답은 이번 기기 테스트의 검증 범위가 아닙니다.

첫 Gradle 기기 테스트 실행 후 도구가 앱 패키지를 정리해 다시 설치했습니다. 기존 로그인·초기 설정 보존 여부는 확인되지 않아 재확인이 필요합니다. 이후에는 앱을 삭제하지 않는 replacement install 및 직접 instrumentation 방식으로 검증했습니다.
