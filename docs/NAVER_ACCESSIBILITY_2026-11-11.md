# Naver walking start assist — 2026-11-11

Voice destination requests retain the existing Naver walking-route handoff. An optional accessibility service attempts one 안내시작 click only after a fresh matching Naver window, exact destination, selected walking mode and one enabled visible start button are confirmed. Requests expire after 20 seconds and are consumed atomically, with cancellation/replacement/whole-session stop and service lifecycle cleanup. Other apps are observed only for foreground transitions; their screen content is not inspected. No screen logs, gestures, screenshots, arbitrary coordinate clicks or API keys are used.
