# 팀원 UI 통합

2026-10-16 `prj_test.zip`의 `activity_main.xml`, `MainActivity.kt`, 전원 버튼 배경을 참고해 기존 Compose 홈 화면에 적용했다.

- 남색 배경(#0F172A), 패널(#1E293B), 녹색 실행 상태와 빨간색 OFF, 원형 전원 버튼, 상단 AI GLASS ARIA 타이틀을 반영했다. 앱 기본 테마는 시안의 다크 스타일이다.
- 전원 버튼 한 번 터치는 중지 상태에서 기존 권한 처리 후 호출어 대기를 시작한다. 실행 중 한 번 터치는 확인 진동을 준다. 두 번 터치는 전체 서비스를 중지한다. 제스처는 전원 버튼에 한정해 받아쓰기 선택·스크롤·탭 조작과 충돌하지 않게 했다.
- TalkBack은 전원 버튼의 기본 클릭으로 시작·상태 확인을 하고 사용자 지정 접근성 동작 또는 별도 중지 버튼으로 전체 중지할 수 있다.
- 표시 상태는 실제 VoiceState를 따른다. 시안의 로컬 isSystemOn과 장애물 감지 문구는 가져오지 않았다. 현재 앱은 음성 대기·받아쓰기를 제공한다.
- 앱 진입 시 자동 호출어 대기, 수동 받아쓰기·완료, 최종 결과 선택·스크롤, 권한 오류 안내, 설정·안내음 설정은 유지했다.
- 원본 프로젝트의 Gradle 버전, AppCompat/CardView 의존성, 캐시·APK·local.properties는 가져오지 않았다.

## Android Studio 확인

빌드·테스트·Lint는 실행하지 않았다. XML 파싱과 문자열 참조만 정적으로 확인했다.

1. 앱 실행과 자동 대기, 실제 상태에 따른 STARTING/RUNNING/OFF 전환을 확인한다.
2. 전체 중지 뒤 원형 버튼 한 번 터치로 대기를 시작한다. 실행 중 한 번 터치로 중지되지 않는지, 두 번 터치로 마이크가 해제되는지 확인한다.
3. 호출어·수동 받아쓰기 → 실시간 결과 → 완료 결과 유지와 전체 중지를 확인한다.
4. 홈·설정 이동, 안내음 설정, 진단, 권한 거부 후 설정 이동을 확인한다.
5. 작은 화면·가로 화면·큰 글꼴에서 스크롤과 버튼 접근을 확인하고 TalkBack 시작·전체 중지를 확인한다.
6. `VoiceDemoScreenTest`의 단일/이중 터치 및 기존 상태·결과 회귀 테스트를 실행한다.

## Android 호출어 통합

호출어와 명령은 Android 기본 인식을 함께 사용한다. 정상 Waiting과 재연결/Reconnecting, 음성 안내/Speaking을 구분하고 재시도 횟수·남은 시간을 표시한다. 기존 Sherpa WAV 진단은 제거했다. 백그라운드 실사용 검증은 [VOICE_VALIDATION.md](VOICE_VALIDATION.md)를 따른다.
