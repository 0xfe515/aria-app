# 키와 착용 위치로 추정하는 카메라 높이

상태: **근거 조사·계산식 확정, 앱 코드 적용 전**. 조사일: 2026-10-31.

## 입력과 기준점

사용자에게 키(cm)와 착용 위치를 입력받는다. 어깨 또는 가슴을 사용자가 명시적으로 선택하며, 키는 임의의 기본값으로 저장하지 않는다. 기본 착용 위치 제안은 어깨로 하되 최초 저장 전에 확인받는다.

- 어깨: 견봉(acromiale), 즉 어깨 바깥쪽 뼈 기준 높이 부근에 **카메라 렌즈**를 착용한다.
- 가슴: 유두/젖가슴 높이 수준의 가슴 중앙에 **렌즈**를 착용한다. 목 아래 쇄골·상흉부 위치와 다르다.

몸에 고정된 렌즈의 높이를 근사하는 모델이다. 손에 자유롭게 들거나 앉은 상태에 그대로 적용하지 않는다.

## 일차 출처

Makiko Kouchi and Masaaki Mochimaru, 2006: *Japanese 3-D body shape and dimensions data 2003*, National Institute of Advanced Industrial Science and Technology, H18PRO-503.

- [AIST/HQL 데이터베이스 개요·표본·인용 및 이용 안내](https://www.airc.aist.go.jp/dhrt/fbodydb/index.html)
- [공식 집계 통계 PDF](https://www.airc.aist.go.jp/dhrt/fbodydb/2003_Statistics.pdf), 인쇄 1쪽(남성)·3쪽(여성), 항목 2·5·8.
- [공식 측정 항목 정의](https://www.airc.aist.go.jp/dhrt/fbodydb/data/item-list.html)

2003년 측정한 일본 성인 남성 49명과 여성 48명의 소규모 표본이다. 통계표의 연령 범위는 남성 20.3–30.5세, 여성 21.2–35.5세다. 공식 안내는 공개 집계 통계 사용에 별도 신청이 필요 없다고 명시한다. 개인별 자료는 복제하지 않는다.

아래 값은 공식 통계표의 평균이며 단위는 mm다.

| 집단 | N | 키 평균 | 견봉 높이 평균 | 가슴 높이 평균 |
|---|---:|---:|---:|---:|
| 남성 | 49 | 1696.7 | 1363.5 | 1217.3 |
| 여성 | 48 | 1578.3 | 1268.1 | 1129.1 |

가슴 항목은 남성 nipple height, 여성 bust height라는 서로 대응하는 측정 기준을 사용한다. 장착 위치를 이 수준으로 정의하는 것은 앱의 설계 선택이며 모든 가슴 장착 위치를 대표한다는 뜻은 아니다.

## 비율 유도와 사용할 식

성별을 입력받지 않는 초기 모델로, 표본 수로 가중한 **평균 높이의 비율**을 사용한다. 개인별 높이/키 비율의 평균이나 회귀계수는 아니다. 성별 표본 비율은 모집단 비율로 재가중하지 않는다.

```text
D = 49 × 1696.7 + 48 × 1578.3 = 158896.7
S = 49 × 1363.5 + 48 × 1268.1 = 127680.3
C = 49 × 1217.3 + 48 × 1129.1 = 113844.5

r_shoulder = S / D = 0.8035428048537193
r_chest    = C / D = 0.7164686239550601

cameraHeightMeters = statureCm / 100 × r_position
groundYRelativeToCamera = -cameraHeightMeters
```

170cm 입력 시 어깨 약 **1.3660m**, 가슴 약 **1.217997m**다. 화면에는 어깨 약 137cm·가슴 약 122cm처럼 반올림해 '추정 렌즈 높이'로 표시한다. 반올림 전 값을 거리 계산에 사용한다.

## 거리 계산과의 연결 계약

키 기반 높이는 장면의 깊이를 직접 제공하지 않는다. 단안 기하 방식에서는 카메라 내부 보정값으로 접점 픽셀의 광선을 만들고, 실시간 센서 자세로 중력 기준 좌표계로 회전한 후 높이 `-h`의 가상 바닥과 교차시킨다.

```text
ray_camera = inverse(K) × [u, v, 1]
ray_gravity = R_camera_to_gravity × ray_camera
t = -h / ray_gravity.y    (y축 위쪽 양수인 좌표계)
point = t × ray_gravity
```

`t > 0`인 바닥 방향 광선만 사용한다. 수평선 부근, 오래된/부정확한 센서 자세, 접점 가림, 회전·크롭 변환 누락에서는 거리를 제공하지 않는다. 렌즈 높이와 각도를 픽셀당 일정한 미터 배율로 대체하면 안 된다. 화면 하단 중앙은 진행 방향 표시 기준이며 사용자 발이나 지면상의 고정 위치가 아니다.

Android에서 얻는 카메라 내부 보정값·센서 크기·초점거리 및 실시간 자세 정보는 이 계산을 위한 별도 입력이다. 센서 좌표계에서 카메라 좌표계로의 축 변환, 실제 분석 영상의 회전·크롭·줌을 반영해야 한다.

## 한계와 구현 수용 기준

- 이 계수는 한국인 전체·아동·고령자·모든 체형의 검증된 평균이 아니다. 표본 범위를 벗어난 키에도 같은 비율을 적용하면 외삽이다.
- 키 입력 허용 범위를 정하더라도 그 전체 범위에서 정확도가 검증됐다는 뜻은 아니다.
- 옷·장착구·렌즈 위치·신발·구부정한 자세에 따른 차이를 포함하지 않는다. 카메라 높이를 실측해 보정하는 기능은 추후 선택적으로 추가할 수 있다.
- 높이를 10% 크게 추정하면 같은 광선과 평면 조건에서 계산 거리도 약 10% 크게 나온다. 통계표의 집단 표준편차를 개인별 거리 오차나 신뢰구간으로 바꾸지 않는다.
- 경사·계단·낙차는 평평한 가상 바닥 가정을 위반한다. 추정 거리와 실제 보행 안전성을 동일시하지 않는다.
- 앱은 최초 입력, 저장·재실행 복원, 착용 위치 변경, 잘못된 키 입력, 측정 중 설정 변경 후 이전 거리 무효화를 검증해야 한다.
- 실제 코드 통합 후 빌드·단위 테스트·Lint와 Pixel 3 기기 테스트가 필요하다. 이 문서 작성 시 앱 코드 변경이나 신규 APK 설치는 수행하지 않았다.
