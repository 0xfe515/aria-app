# 2026-11-04 야외 테스트 기록

## 시작

- 앱의 마이크·카메라·알림 권한을 확인합니다.
- 설정에서 키와 가슴/어깨 장착 위치를 맞추고, 실제 장착 방향으로 정면 보정합니다.
- Home의 모델/카메라 상태와 상대 방향 표시를 확인합니다. 상대 방향선은 기기의 보정 기준 회전을 나타냅니다.
- Gemini 질문을 시험하려면 설정에 본인 API 키를 입력합니다. 키 없이도 로컬 음성·카메라·지도 기능을 시험할 수 있습니다.

## 확인할 흐름

1. 호출어 후 로컬 음성 명령과 화면 숨김/표시를 확인합니다. 30초 유휴 후 탭으로 화면을 복원합니다.
2. 정지/직선 보행/회전에서 위험 알림·거리·방향 표시를 관찰합니다.
3. 지도 앱을 열었다가 Aria로 돌아옵니다. 지도 검색 연결과 카메라 세션 지속 여부를 각각 기록합니다.
4. 알림의 모니터링 중지를 누르고, Home에서 명시적으로 다시 시작합니다.
5. Gemini 일반 질문/사진 질문을 요청하고 취소합니다. 위험 경고가 질문 응답보다 우선하는지 확인합니다.
6. 잠시 사용한 후 발열·배터리·음성 인식 지연·프레임 갱신 지연을 기록합니다.
