# ARIA 음성 명령

호출어 뒤에 한 가지 요청을 말합니다. 아래 표현은 로컬에서 명령으로 해석합니다. 사진 내용을 답하거나 실제 장소를 찾는 단계는 기존 연결 기능을 사용합니다.

| 기능 | 말하는 예 |
| --- | --- |
| 앱 음량 지정 | 볼륨 50퍼센트 / 음량 70프로 / 소리 크기 절반 |
| 앱 음량 조절 | 볼륨 올려 / 음량 낮춰 / 좀 더 크게 / 좀 더 작게 |
| 반복 알림 줄이기 | 경고 빈도 낮춰 / 경고 덜 자주 / 알림 좀 줄여 |
| 반복 알림 늘리기 | 경고 빈도 높여 / 자주 알려줘 |
| 기본 반복 빈도 | 경고 빈도 기본으로 |
| 주의 알림 끄기 | 주의 단계 꺼 / 주의 알림 끄기 / 위험할 때만 알려줘 |
| 주의 알림 켜기 | 주의 다시 켜 / 주의도 알려줘 |
| 설정 읽기 | 현재 알림 설정 알려줘 / 음량 얼마야 / 경고 빈도 어떻게 돼 / 주의 알림 켜져 있어 |
| 화면과 메뉴 | 홈으로 돌아가 / 설정 화면 열어주세요 / 화면 숨겨 / 화면 보여줘 |
| 보행 상태와 보정 | 보행 상태 알려줘 / 정면 다시 보정해줘 |
| 음성 안내 켜기·끄기 | 안내 소리 켜 / 안내 소리 꺼 |
| 도움말 | 명령어 뭐 있어 / 도움말 |
| 취소·정지 | 취소 / 전체 중지 |

음량은 ARIA의 음성·효과음에 적용하며, 0~100퍼센트 범위입니다. 수치 없는 올리기·내리기는 10퍼센트포인트씩 조절합니다. 휴대폰 전체 미디어 음량이나 기존 음성 안내 켜기·끄기 설정은 따로 유지됩니다. 음량 0에서는 결과 음성이 들리지 않을 수 있으며, 다시 음량을 높여 사용할 수 있습니다.

`50`뿐 아니라 `오십`, `칠십`, `이십` 같은 한자식 수사도 지원합니다. `쉰` 같은 고유어 수사는 아직 지원하지 않습니다. 부호·소수·범위 밖 값이나 값이 빠진 요청은 다시 묻습니다.

반복 빈도는 자주·보통·덜 자주 세 단계입니다. 같은 위험의 반복 간격을 조절하며 감지 기준을 바꾸지 않습니다. 새 위험이나 더 높은 경고 단계는 별도로 처리하므로 정확히 일정한 주기로만 울리는 타이머는 아닙니다. 주의 끄기는 주의 단계의 알림을 끄며, 더 높은 경고·긴급 단계와 화면의 실제 감지 결과를 유지합니다. 일반 설정 화면에서도 같은 값을 확인하고 바꿀 수 있습니다.

## 길안내

- 충주시청까지 안내해줘
- 충주시청으로 데려다줘
- 충주시청까지 길 좀 찾아줘
- 충주시청 가는 방법 알려줘
- 충주시청 어떻게 가
- 충주시청까지 걸어갈래
- 충주시청까지 도보로 안내해 주세요
- 네이버 지도로 충주시청 안내해줘

현재 연동은 도보 길안내를 기준으로 합니다. 지도 앱에서 경로를 여는 것과 지도 앱의 음성 안내를 자동 시작하는 것은 다르며, 제공되는 연동 범위에 따릅니다.

## 사진 질문

- 앞에 뭐 있어
- 이게 뭔지 알려줘
- 지피티, 이거 무슨 색인지 알려줘
- 글씨 읽어줘
- 사진 찍고 확인하고 설명해줘

사진 질문은 원래 질문의 내용을 보존합니다. 명시적인 촬영·전송 금지와 취소를 우선 처리합니다.
